## 开发命令

需要Node.js22+与pnpm；依赖以`pnpm-lock.yaml`为准。

```powershell
pnpm install
pnpm dev
pnpm build
pnpm check
pnpm test
pnpm start
```

`pnpm build`输出预渲染页面到`dist/client`；正式预览通过Node服务器运行，默认4173端口。发布前填写`SITE_URL`并重建以生成正式域名的SEO链接。尚未进行外网部署。

Cloudflare Pages使用 `pnpm run build:pages`，输出目录为 `dist/client`，已包含留言Worker与语言404适配。技能详情和天赋树已接入83位精选武将，支持等级预览。纸纹、边缘水墨和头图飞白素材记录见 `docs/视觉素材补充-20261027.md`。

## Cloudflare Workers（当前控制台）

当前Workers项目使用根目录wrangler.jsonc配置输出目录；assets.directory为./dist/client。构建命令pnpm run build:workers，部署命令npx wrangler deploy，仓库根目录为/。Node 24、pnpm 11.25.0，Wrangler固定4.153.0。Workers与Pages共用现有留言／韩文404边缘处理，静态页面优先由ASSETS提供。

pnpm-workspace.yaml已显式声明根包，避免云端旧pnpm报packages field missing or empty；package.json已锁定packageManager，云端也建议填写PNPM_VERSION=11.25.0。需要提交package.json、pnpm-lock.yaml、pnpm-workspace.yaml、.node-version、wrangler.jsonc与新增构建脚本。

详细步骤见[Cloudflare Workers部署说明](docs/Cloudflare-Workers部署说明.md)。已有Pages构建入口继续使用pnpm run build:pages。

## 游戏介绍 · 三国：乱世苍生
> 经营一城，汇聚英才，在群雄逐鹿中寻找安定天下之路。

《三国：乱世苍生》是一款以汉末三国为背景的单人策略游戏，融合城池经营、武将成长、回合制战场、白刃战与武将单挑。你将扮演一方君主，安排内政、招揽人才、筹措粮草，在群雄之间谋求生存与壮大，最终争取一统天下。

从山河舆图上的势力布局，到方格战场上的调兵遣将，再到将士接战与阵前单挑，游戏将不同层面的决策串联起来。后方积累的粮食、人才和兵力，是前线行动的底气；战场上的胜负与损耗，也决定了接下来如何经营、休整和再度出征。

### 选择君主，从不同的乱世起点出发

在“董卓之乱”“群雄争霸”“卧龙凤雏”“天下三分”等历史剧本中，选择君主与势力，面对不同的城池分布、人才配置和周边形势，规划自己的征途。

据守一隅，先养民积粮；延揽贤才，等待破局之机；或趁局势变化，主动出兵争夺要地。不同的起点，需要不同的经营节奏与用兵思路。

### 经营城池，照看粮草与人心

城池是征战的根基。发展农业与商业、扩充人口、加强防灾，逐步积累金钱、粮食和兵员；通过征兵、调遣、运输和粮食交易，为军队做好准备。

每月可以使用的指令有限。派谁执行、先办哪件事、留下多少资源应对变局，都需要权衡。眼前的一次扩军，可能意味着后续更紧张的供给；暂缓攻势、休养生息，也可能为下一场战事争取主动。

与此同时，人口、民心、灾害与地方动荡也需要持续关注。旱灾、水患、疫病，以及民变、兵变，都可能打乱既定部署。稳固后方，是君主需要长期面对的课题。

### 招揽与培养，让人才各尽其用

寻访在野武将，任命太守，调配文臣武将，通过封赏维系忠诚，逐步建立自己的势力班底。对外则可以侦察敌情、离间对手、劝说人才，或借助结盟与停战调整局势。

武将各有能力、固有特长与成长方向。随着等级提升，天赋树中的能力逐步解锁，部分武将还能习得专属谋略、战法或阵法。结合武器、防具、宝物和带兵配置，安排适合他们的职责：治理地方、领军作战、阵前交锋，或施展谋略。

把有限的人才放到合适的位置，也是经营势力的一部分。

### 多层战斗，从调兵遣将到阵前交锋

### 回合制战场：把握地利，安排进退

在方格战场上指挥部队移动、进攻、驻守与施策。山林、河流、城池等地形影响行动与交战，战场视野和天气变化也会影响判断，部分计策还受到地形与天气的限制。

行军粮草同样需要计算。是集中兵力争取速胜，还是利用地形周旋、等待机会？用火计、伏兵、诱敌等手段创造优势，在部队接战之前做好布局。

### 白刃交锋：配置阵型，指挥将士

当部队接战，战斗进入更具体的白刃场景。平原、山林、水面与城防等环境带来不同的交锋空间，武将与士卒共同参与战斗。

配置阵型，向主将、分队或全军下达进退、待机等指令，并在合适的时机发动战法。兵种搭配、士气、地形与武将特长共同影响战局，需要根据交锋过程调整安排。

### 武将单挑：观察状态，判断取舍

两军交锋之间，武将也可能在阵前一决高下。观察双方体力、斗志与战斗状态，选择进攻、挑衅、劝降或撤退，在招式交锋中判断继续作战的机会与风险。

单挑与白刃战、整个战场相互衔接。主将的进退与胜负，可能牵动所属部队接下来的处境。

### 巡查乡野，在征战之外发现机遇

派遣武将巡查周边、拜访游历名士，寻找人才、情报与宝物。巡查也可能遭遇山贼、江贼等地方势力，进入讨伐与交战，处理城池周边的威胁。

这些经历为经营与成长带来新的机会，也让每月的安排多了一层取舍：留在城中积累实力，还是派人外出，尝试发现新的转机。

### 复古二维画面，呈现山河与群像

游戏以具有手绘质感的武将头像、像素将士、山河地图与卷轴式界面，呈现汉末三国的群雄与城池。从江河沿岸的营垒，到城关、山林与舟船上的交锋，不同场景共同构成这段征途。

在一城一地的经营中积蓄力量，在一次次用人与征战中推进局势。你所追求的天下，将从当下的每一道命令开始。

## D1留言与Turnstile

留言由Worker在服务端调用D1 REST /raw，兼容现有messages表；浏览器继续调用本站API。公开账户／数据库／Site Key已配置，私密值由运行时D1_API_TOKEN与TURNSTILE_SECRET_KEY提供，不在源码或构建产物中。D1可读但安全验证未配置时仍禁止投稿；成功投稿直接公开。见docs/D1留言与Turnstile配置.md。
